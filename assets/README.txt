Place an equirectangular star map here. The renderer tries, in order:

    starfield.hdr   (Radiance .hdr — true HDR, preferred)
    starfield.png   (8-bit fallback — already shipped, 4096x2048 procedural)
    starfield.jpg

If none load, an in-shader procedural starfield is used.

------------------------------------------------------------------------
Already included: `starfield.png` — a procedural 4096x2048 Milky Way panorama
generated by `make_starfield.py`. Regenerate any time:

    pip install numpy pillow
    python3 assets/make_starfield.py            # rewrites starfield.png
    python3 assets/make_starfield.py --hdr      # also writes starfield.hdr

For a real photographic HDRI: ESO/NASA release Milky Way panoramas under
CC BY 4.0 (attribution required) — drop the .hdr next to this file.
